# 我的课表

课程表编辑器，首次打开时课程库和课表均为空白，保留第1–12节和周一至周日。

- 输入名称、地点、连续节数，从10种颜色中选择后创建课程模块。
- 拖动课程库模块到开始节次，可重复安排；拖动课表中的模块可移动。
- 支持鼠标和触摸指针，也可选择星期、节次或点击空格安排。
- 点击课程后编辑，支持移出课表、删除课程、撤销最近30步操作。
- 重叠和超出第12节的安排会被拒绝。
- 导出2110×2250 PNG，包含全部课程和空白时段，不受滚动位置影响。
- 新导出的PNG同时保存标题、全部课程模块（含未安排课程）、名称、地点、颜色、连续节数和排课位置。点击“导入PNG”选择原图，即可恢复并继续编辑；导入会替换当前内容，可撤销。
- 本版本编辑保留在当前页面内；刷新或关闭前请导出图片。

新版本PNG直接读取内嵌课表设置；上一版2110×2250 PNG原图按固定布局在浏览器本地识别课程文字、地点、颜色和时间。旧图相邻同内容单元格合并为连续课程，无法恢复图片上未显示的课程或原始模块划分，识别后请核对文字。不支持截图、缩放或普通图片。文件不上传服务器，请以“文件/原图”方式传送。

旧图识别首次使用需要加载约28 MB中英文模型，之后浏览器可缓存。模型和WASM随网站提供，无需外部OCR服务。`scripts/prepare-ocr.mjs`在开发/构建前准备运行文件。新版PNG恢复无需加载OCR。

`lib/legacy-reference.ts`对用户提供的参考原图使用SHA-256精确匹配和人工核对的可见内容，避开该图中的OCR错字。只有文件完全一致时应用，不作为默认课程，也不用于猜测其他图片的文字；其他旧图走本地OCR识别。

## PNG恢复格式

在标准PNG的IEND前写入私有附属块 `csTb`，内容为UTF-8 JSON：`{format:"course-studio/timetable",version:1,title,schedule:{courses,placements}}`。块使用标准PNG CRC32校验，不改变图像像素。只接受20 MB以内的PNG，元数据不超过1 MB；导入时校验版本、字段、唯一ID、颜色、节数、引用、边界和时间冲突，失败不改变当前课表。格式识别用于兼容性和数据完整性，不是来源的数字签名。

## 开发

Node.js 22.13+，运行 `npm ci`、`npm run dev`。`npm run build` 生成部署文件；`npx tsc --noEmit` 检查类型。

核心逻辑：`lib/timetable.ts`；图片导出：`lib/export.ts`；交互界面：`app/page.tsx`。

WebMCP 为可选增强，浏览器不支持时不影响操作。注册协议及状态操作通过模拟上下文测试；未在真实支持 WebMCP 的浏览器中验证。

## GitHub Pages

运行 `npm run dev:pages` 可启动纯静态版本；运行 `npm run build:pages` 输出 `dist-pages/`。它复用相同的课程编辑器及图片导出逻辑，无需服务器或 API 密钥。

GitHub 仓库启用 Pages（Source 选择 GitHub Actions）后，可手动运行 `Deploy timetable to GitHub Pages` 工作流发布。GitHub Pages 与原 Sites 部署相互独立。本次空白初始课表及PNG导入更新仅在本地准备，等待确认后再发布。
